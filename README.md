# Python Refresher

This repository contains Python refresher examples, structured from basics to advanced topics.

## Structure

- `01_basics/` - Hello World, Variables, Data Types, Operators, Input/Output, Comments
- `02_control_flow/` - If-Else, Loops, Match-Case, Ternary Operators
- `03_functions/` - Functions, *args and **kwargs, Lambda, Decorators, Generators
- `04_data_structures/` - Lists, Tuples, Dictionaries, Sets, Comprehensions
- `05_file_io/` - File Read/Write, CSV, JSON, Pickle
- `06_oop/` - Classes, Inheritance, Magic Methods, Properties, Abstract Classes
- `07_modules/` - Imports, Packages, `__init__.py`, `__name__ == "__main__"`
- `08_exceptions/` - Try/Except, Custom Exceptions, Context Managers
- `09_advanced/` - Threading, Multiprocessing, Async/Await, Regex, Type Hints
- `10_real_world/` - Web Scraping, API Requests, Database, Logging, Testing

## Setup (optional)

Some examples require installing packages:

```bash
pip install -r requirements.txt
```

Enjoy coding! 🚀
